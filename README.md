Student Marks Management System

Python Lab Course-End Project

A Python-based application designed to manage student records and marks, calculate academic results, and store student data using file handling.

---

Project Overview

The Student Marks Management System is developed using Python to simplify student record management. It allows users to maintain student information and marks through a menu-driven interface.

This project demonstrates fundamental Python programming concepts, functions, conditional statements, loops, and file handling.

Features

- Add student records
- Store and manage student marks
- Calculate total marks and percentage
- Display student results
- Save and retrieve records using JSON
- Simple and beginner-friendly interface

«Note: The listed features should match the functionality implemented in your "main.py" file.»

Technologies Used

- Programming Language: Python 3
- Data Storage: JSON
- Modules: "json", "os"
- Code Editor: Visual Studio Code

Installation and Execution

Prerequisites

- Python 3 installed on your computer
- Visual Studio Code or any Python-supported editor

Steps to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

python main.py

If your system uses the Python launcher, you can also try:

py main.py
